# FixIt Abuja — Environment Variables

Copy-paste these into Vercel → Project → Settings → Environment Variables.
Every value below is a working default — change any of them later, just
keep the matching value updated wherever else it's referenced (noted below).

## Already yours (Gmail SMTP)

```
SMTP_HOST
SMTP_PORT=
SMTP_USER=
SMTP_PASS=<see note 1>
```

## New — bulk email business inbox (optional)

```
BUSINESS_EMAIL=info@justservices.pro
```
Where form-submission notifications land. If you skip this, it defaults to
`SMTP_USER` instead.

## New — Google Sheets backend (subscribers, bookings, campaign log)

```
SHEETS_ENDPOINT=<see note 2>
SHEETS_ADMIN_TOKEN=WRjA1I_7c-NtDe5mju9024ticxM2V-p5
```
`SHEETS_ADMIN_TOKEN` must always match the `ADMIN_TOKEN` constant near the
top of `google-apps-script.gs` — they're already set to the same value above,
so no extra step needed unless you change one of them.

## New — admin dashboard API auth

```
ADMIN_PASSCODE=Its1984@1
```
Must match `ADMIN_PASSCODE` inside `admin.html` (already set to the same
value). This is what lets the Bulk Email panel's buttons call the
`/api/subscribers` and `/api/send-bulk-email` endpoints.

## New — cron job protection

```
CRON_SECRET=oWgxZq5HbIdfl2n9KgZeHzACJdvgoARK
```
Must match the `secret=` value already baked into the cron path inside
`vercel.json`. Stops strangers from triggering bulk sends by guessing the URL.

---

### Note 1 — SMTP_PASS
Use a Gmail **App Password** (16 characters, no spaces), not your normal
Gmail password — Gmail blocks regular-password SMTP logins from third-party
apps. Generate one at https://myaccount.google.com/apppasswords (requires
2-Step Verification turned on for that Gmail account).

### Note 2 — SHEETS_ENDPOINT
This is the one value that can't be defaulted — it's generated by Google
when you deploy the script:
1. sheets.google.com → new blank spreadsheet.
2. Extensions → Apps Script → paste in `google-apps-script.gs`.
3. Deploy → New deployment → Web app → Execute as "Me" → Who has access "Anyone" → Deploy.
4. Copy the URL (ends in `/exec`).
5. Paste it as `SHEETS_ENDPOINT` here, AND as `FIXIT_SHEETS_ENDPOINT` in `config.js`.

Once this is set, subscriber capture, bulk email, and the automatic
bi-weekly campaign all start working with no further configuration.
